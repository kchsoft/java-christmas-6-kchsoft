# 객체
- 식당
- 입력
- 손님
- 메뉴판
- 음식
- 음식 종류
- 종업원
- 주문
- 주의사항
- 결제
- 이벤트 플래너
- 이벤트 6개(크리스마스 디데이,평일 할인, 주말 할민, 특별 할인, 증정 이벤트, 배지 이벤트)
- 이벤트 결과
- 영수증
- 출력

# 메시지
- 방문 날짜를 입력하라  

<br>  
- 입력 데이터를 검증하라
- 음식을 주문하라
- 1. 메뉴를 찾아라
- 2. 종업원에게 전달해라 

<br>  

- 주문을 만들어라
- 주의 사항을 확인하라  
- - 총주문 금액이 10,000이상인지 확인하라  
- - 음료만 주문했는지 확인하라  
- - 주문 메뉴 개수가 20개 이하인지 확인하라

<br>

- 결제하라  
- 이벤트가 적용되는지 확인하라  
- 1. 할인 전 총주문 금액이 12만원 이상인지 확인하여 샴페인 1개를 증정하라(증정 이벤트)  
- 2. 크리스마스 기간에 맞춰 할인하라(크리스마스 디데이 할인)  
- 3. 달력에 별이 있는 날이면 할인하라 (특별 할인)  
- 4. 평일이라면, 디저트 메뉴를 확인하여 할인하라(평일 할인)  
- 5. 주말이라면, 메인 메뉴를 확인하여 할인하라(주말 할인)  
- 6. 총혜택 금액을 종합하여 배지를 증정하라(이벤트 배지)  
- 이벤트 결과를 만들어라
- 영수증을 만들어라  

<br>  

- 각각의 이벤트 내역을 출력하라
